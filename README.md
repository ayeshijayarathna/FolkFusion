# 🎨 FolkFusion — Traditional Folk Arts Preservation Platform

## 📌 Project Overview
**FolkFusion** is a full-stack web application designed to preserve and promote **Sri Lankan traditional folk arts**.  
It integrates **artist management, cultural heritage, e-commerce, learning systems, AR visualization** into one unified platform.

**Tagline:** *"Discover the Beauty of Folk Arts"*

---

## 🚀 Tech Stack

### Frontend
- React + Vite  
- React Router DOM  
- Tailwind CSS  
- Lucide / Remix Icons  
- Recharts  
- Stripe Elements  

### Backend
- Node.js + Express  
- MongoDB (Mongoose)  
- JWT Authentication  
- Bcrypt  

### Storage
- Cloudinary (images)  
- Local `/public/models` (3D GLB files)  

### Payments
- Stripe (Card payments + Webhooks)  

### Real-time
- Socket.IO (notifications)  

### AI
- AI Insights endpoints (admin & artist dashboards)  

### Email
- Custom Email Service (40K+ lines)
